# Canonix

- `index.html` : structure et styles
- `config.js` : vos réglages (Supabase, contact, catégories, admin démo)
- `app.js` : logique de l’application
- `schema.sql` : base Supabase · `sw.js` + `manifest.webmanifest` : PWA

## Synchroniser vos modifications avec Claude
1. Modifiez vos fichiers en local.
2. Dans la conversation, envoyez-moi les fichiers modifiés (joignez-les au message).
3. Je pars de VOTRE version, j’applique mes changements dessus et je vous renvoie les fichiers.
Astuce : mettez vos réglages dans `config.js`, il ne change presque jamais.
